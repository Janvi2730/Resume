# Janvi Pagar — Portfolio

A clean, minimal, professional portfolio with subtle 3D/parallax scroll effects.

## Files

- `index.html` — portfolio structure and content
- `styles.css` — responsive design, 3D hero, cards and animations
- `script.js` — scroll progress, reveal animations, tilt effects and case-study modals

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a new GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will provide your portfolio URL.

## Add your photo

The About section currently has a clean placeholder. Replace the `.photo-placeholder` block in `index.html` with an `<img>` tag, or add a local `profile.jpg` and use:

`<img src="profile.jpg" alt="Janvi Pagar" />`

## Customise

Search the CSS variables at the top of `styles.css` to change the beige palette, typography or accent.
