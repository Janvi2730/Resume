# Janvi Pagar — Portfolio

Clean, minimal, professional portfolio with subtle 3D/parallax motion, scroll reveal and case-study popups.

## GitHub Pages
1. Upload `index.html` and `styles.css` to the **root** of your repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch** → `main` → `/ (root)` → Save.
4. Wait a few minutes for the live URL.

Keep `index.html` and `styles.css` in the same folder.
